# 수업이야기 카드뉴스 콘텐츠 추가 가이드

`case`(활용 수업 사례) / `edtech`(에듀테크 활용 수업 사례) 카드뉴스에 새 콘텐츠를 올리는 방법입니다.
`class-cards-template.csv`에 내용을 채워서 전달해 주시면 반영합니다.

## 1. CSV 채우기

`class-cards-template.csv` 열 설명:

| 열 | 설명 |
|---|---|
| `section` | `case` 또는 `edtech` (고정값) |
| `id` | 폴더명 겸 식별자 — 영문 소문자·숫자·하이픈만. 아래 2번 폴더명과 **반드시 동일**해야 함 |
| `level` | `elem`(초) / `mid`(중) / `high`(고) |
| `title` | 카드 제목 |
| `desc` | 카드뉴스 1면(썸네일)에 있는 안내 문구를 그대로 옮겨 적은 한 줄 설명. 라이트박스 사이드바에 표시되고, 사이트 검색에도 잡힘 |
| `publisher` | 발행사 (선택, case 위주) |
| `subject` | 대상 과목 (선택) |
| `gradeTerm` | 학년·학기 (선택) |
| `tool` | 함께 쓴 에듀테크 도구 이름 (선택). 값이 있으면 카드·라이트박스에 태그로 표시됨 |

- `publisher` / `subject` / `gradeTerm` / `tool`은 값이 있는 것만 태그로 표시되므로 없으면 빈칸으로 둡니다.
- `case`에만 있는 PDF(수업안)는 CSV에 적는 항목이 아닙니다 (아래 2번 참고).

## 2. 이미지·PDF 파일 배치

각 행의 `id`와 **똑같은 이름**으로 폴더를 만들고 그 안에 파일을 넣습니다.

```
src/assets/cards/{section}/{id}/
  01.png   ← 카드뉴스 1면 = 목록 썸네일
  02.png
  03.png ...
  아무이름.pdf   ← case 전용, 수업안 PDF (있으면 파일명 아무거나 상관없음)
```

- 이미지 폴더가 비어 있어도 빌드는 통과하며, 그 카드에는 "탑재 예정" 배지가 뜹니다.
- `case` 섹션은 PDF 파일이 같은 폴더 안에 있으면 자동으로 "수업 사례 PDF 내려받기" 버튼이 활성화됩니다. 없으면 "탑재 예정"으로 표시됩니다.
- `edtech`는 PDF 기능이 없으므로 PDF 파일을 넣어도 표시되지 않습니다.
- 원본 이미지 용량이 커도 상관없습니다 — 빌드 시 자동으로 webp로 재생성해서 최적화합니다.
- 카드뉴스 비율은 1688×2110(≈4:5)에 맞춰져 있습니다.

## 3. 에듀테크 도구 링크 등록 (tool 값을 채운 경우)

`tool`에 적은 도구 이름이 `src/data/toolLinks.ts`에 등록되어 있으면, 라이트박스에 "○○ 더 알아보기" 버튼이 자동으로 뜹니다.

```ts
// src/data/toolLinks.ts
export const toolLinks: Record<string, string> = {
  캔바: 'https://www.canva.com/',
  패들렛: 'https://padlet.com/',
  // ...
};
```

- CSV의 `tool` 값과 이 파일의 키가 **정확히 일치**해야 합니다 (오타 주의).
- 등록되지 않은 도구는 버튼 없이 태그만 표시됩니다 — 링크를 모르면 억지로 채우지 말고 비워 두는 편이 안전합니다.
- 새 도구를 쓴다면 이 파일에 한 줄 추가해서 같이 전달해 주세요.

## 4. 전달 방법

1. CSV에 내용 작성
2. 각 행의 `id` 폴더를 만들어 이미지(+PDF) 배치
3. 새로 쓴 `tool`이 있으면 `toolLinks.ts`에 추가할 이름·링크도 함께 안내
4. CSV + 이미지 폴더를 전달
