
## 2. 수업이야기 — 신규 3개 페이지

### 2-1. 메뉴 순서

`수업이야기` 드롭다운에서 **`수업설계 지원` 위**에 순서대로 삽입:

1. 활용 수업 사례 — `/class/case`
2. 이럴 땐 이렇게 — `/class/howto`
3. 에듀테크 활용 수업 사례 — `/class/edtech`
4. (기존) 수업설계 지원 `/class/curriculum`
5. (기존) 중등 AI·디지털 교육자료 지원 `/class/mid`
6. (기존) 외부: 튜터링, 웹전시관

헤더·사이트맵·`/class` 허브 카드 3곳에 모두 반영 → **§3-1 nav 단일화로 자동 처리.**

### 2-2. 데이터: `src/data/classCards.ts`

```ts
export type Level = 'elem' | 'mid' | 'high';   // 초등학교 / 중학교 / 고등학교
export type Section = 'case' | 'howto' | 'edtech';

export interface CardNewsItem {
  id: string;        // 폴더명 겸 식별자 (영문 소문자·숫자·하이픈)
  level: Level;
  title: string;     // 썸네일 아래 제목
  pdf?: string;      // case 전용, public/pdf/case/{파일명} (없으면 '준비 중')
}

export const classCards: Record<Section, CardNewsItem[]> = {
  case: [], howto: [], edtech: [],   // 예시 주석 포함, 자료 준비되면 여기에 추가
};
```

- 이미지: `src/assets/cards/{section}/{id}/01.png, 02.png …`
  → 컴포넌트에서 `import.meta.glob`로 자동 수집, **01번(1면)이 썸네일**.
- 항목 추가 = 배열에 한 줄 + 폴더에 이미지 드롭. 빌드가 폴더 없는 항목을 감지해 경고.

### 2-3. 컴포넌트: `src/components/CardNewsGallery.astro`

- Props: `section`, `showPdf?`(case만 true).
- 렌더 구조
  - 대분류 헤딩 `초등학교` / `중학교` / `고등학교` (섹션마다 `section-mark` 스타일, 순서 고정)
  - 각 대분류 아래 **3열 갤러리** — `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`
    (모바일 1열 → 태블릿 2열 → 데스크톱 3열. "3열"은 데스크톱 기준)
  - 카드 = **1:1 썸네일(카드뉴스 1면) + 아래 제목**, 기존 카드 토큰
    (`rounded-[var(--radius-card)] border-line shadow-[var(--shadow-card)]`, hover 살짝 떠오름)
  - 항목이 없는 대분류는 **점선 플레이스홀더 카드 3장**으로 레이아웃 확인 가능하게 유지
- **라이트박스 캐러셀**(확정): 썸네일 클릭 → `<dialog>` 전체화면 오버레이에서 1:1 카드뉴스를
  좌우로 넘겨봄. `study.astro`/`contact.astro`의 기존 lightbox 패턴 확장.
  - 좌/우 버튼 + `←`/`→` 키, `Esc`·배경 클릭 닫기, `n / 총 n` 카운터
  - 이미지 미등록 항목은 1:1 점선 플레이스홀더 1장 표시
  - `showPdf`일 때 라이트박스 **하단에 `PDF 내려받기` 버튼** —
    `pdf` 값이 있으면 `download` 링크, 없으면 비활성 + "PDF는 추후 업데이트 예정" 안내
  - 접근성: 포커스 트랩(dialog 기본) · 닫힘 시 트리거로 포커스 복귀 · 버튼 aria-label 한국어

### 2-4. 페이지 3개

`src/pages/class/{case,howto,edtech}.astro` — 동일 골격(제목 + 안내 한 줄 + `<CardNewsGallery/>` +

## 3. 남은 작업(사이트맵·검색 등)

### 3-1. 네비게이션 데이터 단일화 — `src/data/nav.ts`
`Header.astro`와 `sitemap.astro`가 nav 배열을 **복붙 유지 중**(현재도 두 벌). 새 메뉴 3개를 넣으면

### 3-2. 사이트맵 페이지 보강 (`/sitemap`)
- 신규 3개 메뉴 자동 반영(§3-1).
- 4개 네비 그룹에 없는 단독 페이지 묶음 추가: 홈 `/`, 검색 `/search`, 사이트맵 `/sitemap`.
- 푸터에서 `/sitemap` 진입 경로가 있는지 확인, 없으면 추가.

### 3-3. 검색 (`/search`, Pagefind)
- **색상 토큰 정리**: `search.astro`의 커스텀 CSS가 **구 디자인(딥 틸 `#0f7d84` / 코랄 `#e2623b`)에
  하드코딩**되어 현재 네이비 테마와 어긋난다 → `--color-primary-*` / `--color-accent` 기반으로 교체.
- 신규 3개 페이지가 인덱싱되는지 `npm run build` 후 `dist/pagefind`로 확인
  (갤러리 제목·대분류 텍스트가 결과에 잡혀야 함). 라이트박스 중복 텍스트는 `data-pagefind-ignore` 처리.
- 결과 없음 화면에 주요 바로가기 몇 개 노출(검색 이탈 방지).

### 3-4. 깨진 리다이렉트 수정 (`public/_redirects`)
`/class/중등-ai디지털-교육자료-지원 → /class/secondary` 인데 **실제 페이지는 `/class/mid`**
(`/class/secondary`는 존재하지 않음 → 404). 대상 경로를 `/class/mid`로 수정.
